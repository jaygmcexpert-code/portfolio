About

I started out pulling cable and studying for CCNA at nineteen, and ended up just as comfortable in a terminal running show ip route as I am in a code editor shipping a front end.

My background is in enterprise networking — designing topologies, configuring routing protocols, and hardening access layers for organizations that can't afford downtime. Along the way I picked up web development to build the internal dashboards and client-facing tools my networking work kept needing, and it stuck. Today I move between both worlds: laying out a multi-site OSPF deployment in the morning, debugging a React state bug in the afternoon.

What ties the two together is the same instinct — trace the problem to its root, test before you trust it, and document it well enough that someone else could pick it up cold. That's the standard I hold every lab file and every commit to.

Enterprise Network Infrastructure Setup

Problem statement: A growing company needed a scalable network across three floors with isolated departmental traffic and centralized IP management.

Solution: Designed a VLAN structure per department, configured inter-VLAN routing on a Layer 3 switch, ran OSPF between the core and distribution layers, and deployed a redundant DHCP scope with helper addresses.

Outcome: Zero IP conflicts post-deployment, full inter-department isolation verified with ACL testing, and a documented config baseline for future expansion.

Campus Network Design & Security Integration

Problem statement: A campus network needed to separate student, staff, and guest wireless traffic while keeping internal resources protected from external access.

Solution: Configured a wireless LAN controller with SSID-to-VLAN mapping, applied ACLs to restrict guest traffic to internet-only, and set up NAT overload for outbound internet access.

Outcome: Guest devices confirmed unable to reach internal subnets in penetration testing, with no measurable impact on staff network performance.
